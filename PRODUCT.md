# Prompts Célebres

Web personal de Danniel para conservar y reutilizar prompts. La colección permite buscar, filtrar, guardar favoritos, adaptar variables y exportar o importar respaldos JSON.

El manual web contiene doce capítulos y un checklist de veinte puntos con progreso persistente en el dispositivo. La biblioteca se centra en usar la colección; el manual, en leer y consultar.

El encargo actual pide una interfaz clara, cercana, ordenada, con espacio y textos grandes. La implementación y revisión de este encargo son exclusivamente locales. Esto no establece una preferencia permanente ni confirma aprobación de una paleta exacta.

El proyecto usa React 19, Vite, Tailwind CSS 4 y HeroUI. Cuenta con infraestructura existente de Cloudflare Worker y D1. La documentación visual se encuentra en DESIGN.md; las extensiones para Impeccable, en .impeccable/design.json.
